<objective>
Establish the base repository scaffolding, vendor third-party libraries (PapaParse, JSZip, Chart.js), define universal CSS theme variables with sanitized Acme Analytics brand identity, and configure `package.json` and Python test environments.
</objective>

<tasks>
<task id="1">
Create vendor directory (`vendor/`) and populate with localized, minified assets:

- `vendor/jszip.min.js` (downloaded or extracted minified JSZip)
- `vendor/chart.umd.min.js` (Chart.js UMD bundle for zero-CDN offline execution)
</task>

<task id="2">
Create brand style definitions and SVG logo:
- `brand.css`: Define root CSS variables (`--brand-primary: #0f172a;`, `--brand-surface: #1e293b;`, `--brand-accent: #0284c7;`, etc.), typography tokens, and sanitized utility classes.

</task>

<task id="3">
Create project configuration files:
- `package.json`: Project name, test scripts, and validation gate hooks.
- `requirements.txt` and `pytest.ini`: Python environment specifications for preprocessor and test suites.
- `.gitignore`: Ignore `.pytest_cache`, `__pycache__`, `dist/`, `build/`, `.venv`, and temporary test artifacts.
</task>
</tasks>
