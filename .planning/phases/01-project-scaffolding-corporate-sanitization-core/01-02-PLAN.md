<objective>
Implement `generate_mock_data.py` to synthesize realistic, 100% anonymized call center datasets adhering strictly to the 15-column canonical schema, simulating the "Mobile App Update v2.1.0 Connection Incident", and providing deterministic generation for golden test baselines.
</objective>

<tasks>
<task id="1">
Develop `generate_mock_data.py`:
- Schema: 15 canonical columns: `Call ID`, `Date`, `Agent Name`, `Customer Sentiment Score`, `Silence %`, `First Contact Resolution`, `Call Duration (s)`, `Queue Name`, `Adherence %`, `Empathy Score`, `Agitation Level`, `Customer Escalation`, `Reason for Call`, `Transcript Snippet`, `QA Evaluation Score`.
- Anonymization: Zero employee names, zero Dexcom/G7/medical device terms. Generic agent names ("Agent Smith", "Alex Rivera", "Jordan Lee", etc.) and generic customer contact center queries.
- Statistical Distributions: Bimodal silence % distribution, correlation between agitation and escalation, and an incident spike pattern for "Mobile App Update v2.1.0 Connection Incident" across a specified date range.
- CLI arguments: `--count` (default 1000), `--output` (default `sample_calls.csv`), `--seed` (default 42).
</task>

<task id="2">
Generate baseline sample datasets:
- Generate `data/sample_calls.csv` (1,000 records) using seed 42.
- Verify that every record validates against the 15-column schema and produces expected distributions.
</task>

<task id="3">
Create automated test for data generator:
- `tests/test_mock_data.py`: Validates columns, value ranges (Sentiment between -1 and 1, Silence % between 0 and 100, etc.), deterministic output with seed, and absence of proprietary keywords.
</task>
</tasks>

<verification>
- `python generate_mock_data.py --count 100 --output test_sample.csv` runs without errors.
- `python -m pytest tests/test_mock_data.py` passes cleanly.
- String inspection asserts 0 matches for "dexcom", "g7", "g6", "nadine", "bilog".
</verification>
