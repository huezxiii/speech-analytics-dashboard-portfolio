<objective>
Port and sanitize the complete programmatic Power BI generator into `powerbi.js` and implement `regen-powerbi.js`. The generator produces a complete `.pbip` project containing TMDL semantic models and PBIR report definitions with 100% white-label Acme Analytics branding, valid brand PNG assets, and duration-weighted DAX measures.
</objective>

<tasks>
<task id="1">
Generate and register white-label brand PNG assets (`brand-icon.png` and `brand-text.png`):
- Create 100% valid PNG binary buffers matching `0x89 0x50 0x4E 0x47 0x0D 0x0A 0x1A 0x0A`.
- Register base64 text strings in `powerbi.js` under `BRAND_ICON_PNG_BASE64` and `BRAND_TEXT_PNG_BASE64`.
</task>

<task id="2">
Implement `powerbi.js`:
- Set `PBI_PROJECT_NAME = 'SpeechAnalytics'`.
- Define `PBI_THEME` referencing `AcmeTheme.json` with `Acme` display name and harmonious design tokens.
- Implement TMDL semantic model builder (`Calls.tmdl`, `DateTable.tmdl`, `SilenceBuckets.tmdl`, `EmpathyBuckets.tmdl`, `relationships.tmdl`, `model.tmdl`).
- Implement duration-weighted DAX calculations (`[Weighted Silence %]`, `[Weighted Agent QA Score]`, `[Weighted Customer Sentiment]`, period-over-period delta measures with zero-row guards).
- Implement PBIR report definition builder across 4 pages: ExecutiveSummaryHub, OpsQACommand, ComplianceCoaching, and CallDetailDrill (with single-sourced PII notice).
- Implement in-memory validator assertions (`assertGeneratedTextIsClean`, `assertModelTablesAreReferenced`, `assertFieldReferencesResolve`, etc.).
- Implement browser zip generator `generatePowerBIExport(rows, exportMode)`.
</task>

<task id="3">
Implement `regen-powerbi.js`:
- Headless Node.js script reading `dashboard-ready.csv`, running `powerbi.js` inside VM sandbox, validating materialized entries, and writing the complete deliverable tree to `powerbi/`.
</task>

<task id="4">
Wire `index.html` export button:
- Ensure `index.html` includes `<script src="powerbi.js"></script>` and connects `pbiExportBtn` to `generatePowerBIExport`.
</task>
</tasks>

<verification>
- `node regen-powerbi.js` executes without error and materializes `powerbi/SpeechAnalytics.SemanticModel` and `powerbi/SpeechAnalytics.Report`.
- All generated PNG assets have valid 8-byte PNG signatures.
- Zero proprietary terms exist in `powerbi.js`.
</verification>
